# Changelog

All notable changes to the Marcus Arcade suite will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Arcade 2.0.0] - Universal Polish & Catalog Sync

### Added
- Complete catalog index tracking all 21 games with direct links and tech tags.
- Open Graph metadata and dynamic card descriptions for link sharing across Discord, WhatsApp, Twitter/X, and social previews.
- Universal procedural Web Audio engine integration across catalog titles with synthesized zero-lag audio.
- High-impact visual score feedback ("Bright +" bloom & floating dopamine score metrics).
- 2.5D hybrid perspective camera rig and procedural low-poly 3D models for Sky Ace 1944.
- Dynamic death fruit scaling and smooth shrink lifecycle for Neon Viper 3D.

### Changed
- Refreshed main hub UI to display the verified 21-game collection without exception.
- Upgraded Sky Ace 1944 to 2.5D/3D WebGL Three.js architecture with dynamic roll banking kinematics.
- Re-calibrated global game progression and dynamic difficulty adjustment (DDA) curves.
- Synchronized all repository READMEs, sub-game documentations, and the root GitHub profile summary.

### Fixed
- Outdated game counts and stale social preview descriptions across all hub pages.
- Broken asset links and missing back-to-hub navigation buttons in sub-games.
- Infinite ammo and singleton state lifecycle bugs in Stickman Time Crisis 3D.
